## 🌟 核心功能特色

1. **21 维现实场景题库**：
   - 覆盖 7 大脉轮（海底轮、本我轮、太阳轮、心轮、喉轮、眉心轮、顶轮），每轮 3 题。

2. **7 维交互式雷达图**：
   - 基于 Chart.js 渲染莫兰迪低饱和度美学雷达图，直观展现能量通畅度。
3. **高颜值小红书打卡海报生成（裂变利器）**：
   - 基于 Retina 高清 Canvas 算法，手机端可**一键生成 3:4 竖版小红书精美长图**。
   - 包含专属能量人格标签、核心卡点提示、专属赫兹频段与肯定语，支持长按直接保存到手机相册。
4. **内置商业转化跳板**：
   - 结果页无缝嵌入小红书店铺引流卡片（《7天脉轮音频自愈大礼包》）。

## 🌐 免费上线与部署方案（零服务器成本）

因为本项目是**纯前端轻量化静态单页应用**，您无需支付任何服务器费用，推荐以下三种一键上线方案：

### 方案 1：Vercel / Cloudflare Pages（最快，全球 CDN 加速）
1. 将当前文件夹上传到 GitHub 仓库；
2. 登录 [Vercel](https://vercel.com) 或 [Cloudflare Pages](https://dash.cloudflare.com/)；
3. 选择该仓库，点击「Deploy」，**10 秒内即可获得专属 HTTPS 域名链接**（可直接放在小红书主页或私信）。

### 方案 2：国内对象存储（OSS / COS 静态网站托管）
- 适合绑定已备案的国内独立域名，每年成本仅需几元钱，国内访问速度极快。
